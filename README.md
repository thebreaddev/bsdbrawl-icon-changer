# bsdbrawl-icon-changer

This repository stores app icons of every Brawl Stars version, pulled from the iOS app bundle, for use in the icon changer for BSD Brawl.

Each folder is one game version and holds the icons that ship inside that build.

```
v69.252/
    AppIcon60x60@2x.png
    AppIcon76x76@2x~ipad.png
```
