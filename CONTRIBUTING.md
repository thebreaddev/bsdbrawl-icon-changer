# contributing

PRs that add icons for a new game version are welcome.

## how to add a version

1. fork the repo and create a branch
2. add a folder named after the version, for example v70.100
3. put the app icons inside, keep the original file names
4. open a pull request, name it after the version

## rules

- original pngs only, no reencodes or upscales
- nothing besides the app icons, no artwork or screenshots
- folders stay flat, icons only

If a version is missing and you cannot extract it yourself, open an issue and ask.
